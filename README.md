# Task 2: E-Commerce Sales Data Analysis

## Project Overview
This project analyzes e-commerce sales data to understand business performance, identify sales patterns, and generate meaningful customer and product insights.

The analysis uses the cleaned data prepared during Task 1.

## Objectives
- Calculate important sales Key Performance Indicators (KPIs).
- Understand revenue, order volume, average order value, and units sold.
- Identify top-performing products and categories.
- Analyze sales trends over time.
- Explore customer purchasing behavior.
- Summarize findings through clear and understandable observations.

## Tools and Technologies
- Python
- Pandas
- Google Colab
- Jupyter Notebook

## Analysis Performed
1. Load the cleaned e-commerce dataset.
2. Prepare the data required for analysis.
3. Calculate the required sales KPIs.
4. Analyze monthly or other time-based sales trends.
5. Examine category and product performance.
6. Explore customer-related patterns.
7. Document key findings and observations.

## Key Performance Indicators
- Total Revenue
- Total Orders
- Average Order Value
- Total Units Sold
- Top-Selling Category
- Top Revenue-Generating Product

## Expected Deliverables
- Sales analysis notebook
- KPI summary
- Trend analysis
- Customer insights
- Written observations and findings

## Outcome
This task helps explain how the e-commerce business is performing by converting sales data into understandable business information.

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Provide the cleaned dataset generated in Task 1.
3. Run the notebook cells in order.
